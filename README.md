# Sing-box-Pre

在 VPS 上安装和管理代理节点，查看订阅、管理 Argo 隧道，并按需要使用 WARP 分流和 Cloudflare 优选。

安装后输入 `sb` 就能打开中文菜单。**第一次使用，从下面的“安装与导入”开始即可，大多数选项可以保持默认。**

## 安装与导入

### 1. 在 VPS 上运行安装命令

先通过 SSH 登录 VPS，使用 root 用户执行。如果当前不是 root，可先运行 `sudo -i`。

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Pretic/Sing-box-Pre/main/sing-box.sh)
```

出现菜单后选择 `1. 安装sing-box`，按提示完成安装。

普通安装不需要提前准备域名。只有使用固定 Argo 隧道或 Cloudflare HTTPS 订阅时，才需要自己的 Cloudflare 域名。

默认提供给客户端的节点是：

| 节点 | 使用条件 |
| --- | --- |
| **VLESS-Reality** | 客户端能访问 VPS 对应的公网 TCP 端口。 |
| **VLESS-WS-TLS-Argo** | VPS 能连接 Cloudflare Tunnel；不需要额外开放 Argo 入站端口。 |

**HY2/TUIC 等 UDP 节点默认不加入节点输出和订阅。** 不需要使用它们时，保持默认即可。


### 2. 查看节点和订阅

安装完成后运行：

```bash
sb -c
```

也可以输入 `sb`，选择 `5. 查看节点信息`。复制单个节点链接，或把订阅地址添加到客户端。

节点链接用于导入一个连接；订阅地址用于批量导入，并在以后刷新节点。使用订阅后，VPS 上生成了新节点，客户端仍需执行一次“更新订阅”才能获取。

V2rayN、Shadowrocket、Nekobox、Loon、Karing、Streisand 可使用原始订阅。Clash/Mihomo、sing-box、Surge 用户可使用脚本展示的对应转换链接；转换由第三方服务完成，原订阅地址会发送给该服务。

### 3. 在客户端测试连接

导入后，在你实际使用的网络上测试节点。能导入不等于一定能连接；Reality 需要对应端口可达，Argo 需要隧道正常运行。

如果节点能连接，但订阅地址打不开，可以先复制单个节点使用，再检查订阅端口或配置下文的 HTTPS 订阅。

## NAT VPS 怎么安装

如果服务商只提供部分映射端口，新装时使用下面的命令，把 `你的端口` 换成服务商分配的端口：

```bash
PORT=你的端口 bash <(curl -fsSL https://raw.githubusercontent.com/Pretic/Sing-box-Pre/main/sing-box.sh) -i
```

脚本会使用这组端口：

| 用途 | 端口 |
| --- | --- |
| Reality 节点 | `PORT`，TCP |
| HTTP 订阅 | `PORT+1`，TCP |
| TUIC / Hysteria2 | `PORT+2` / `PORT+3`，UDP |

服务商没有开放的端口，不能因为脚本安装成功就从公网访问。**只有一个映射端口时，可以使用 Argo 节点；cfy 也可以基于这个 Argo 节点生成优选入口。**

Argo 的本地端口不用额外映射。HTTP 订阅端口未开放时，可复制节点链接使用，或在有自己 Cloudflare 域名和固定隧道的情况下配置 HTTPS 订阅。

输入 `sb` 打开菜单，按你要做的事情选择：

| 想做什么 | 菜单入口 |

| 管理临时或固定 Argo 隧道 | `4. Argo隧道管理` |

| 修改已有节点 | `6. 修改节点配置` |

## WARP：给指定网站换一个访问出口

WARP 可以让经过节点访问的指定服务使用 Cloudflare 的出口。例如给 Netflix 或 OpenAI 设置分流，其余网站继续使用 VPS 原来的出口。

### 开启分流

1. 进入 `sb → 8. WARP分流管理 → 1. 设置分流服务`。
2. 选择需要分流的服务。
3. 没有添加其他代理时，脚本自动使用内置 WARP；出现出站选择时，选择“内置 WARP”。

首次使用会自动注册这台 VPS 自己的 WARP 身份，不需要手动准备 WARP 账户。VPS 必须允许 WARP 所需的 UDP 出网；这与是否在订阅中显示 HY2/TUIC 节点是两回事。

如果想让**经过这些节点的全部流量**使用 WARP，在“设置分流服务”里选择 `11. 设置全局代理出站`，再选内置 WARP。想恢复原出口，选择同一页的 `12. 恢复服务器原IP出站`。全局设置会替换已有的按服务分流规则，不会改变 VPS 的 SSH 连接或系统默认路由。

### 查看是否正常

进入 `sb → 8 → 5. 查看内置 WARP 状态及解锁情况`。

页面会先检查连接，再显示出口 IP、地区，以及 Netflix、Disney+、ChatGPT、Gemini 的检测结果。检测需要一些时间，页面会显示进度。

| 首页显示 | 代表什么 |
| --- | --- |
| 绿色 `running` | 最近一次 WARP 连接检查通过。 |
| 黄色 `degraded` | 已配置 WARP，但最近一次连接检查失败。 |
| 红色 `not configured` | 还没有配置有效的 WARP。 |

首页状态最多缓存 5 分钟；要立即重新检查，进入上面的状态页面。**`running` 只代表 WARP 能连接，不代表所有平台都已解锁。**

### 更换身份或尝试解锁

仍在 WARP 菜单中：

- **`6. 更换内置 WARP 身份/IP`**：尝试一个新身份，并检查出口是否可用。
- **`7. 自动优选 WARP IP（多平台解锁）`**：按你选择的平台寻找可用候选。可以多选，例如输入 `134`；直接回车默认选择全部四个平台。

新身份不保证带来不同的 IPv4 地址。如果未取得不同 IPv4，脚本也会探测 WARP 的 IPv6 出口，可用且验证通过后才会尝试切换。VPS 没有原生 IPv6，并不等于 WARP 一定没有 IPv6 出口，结果以实际检测为准。

自动优选要求所选平台全部通过才启用候选，选择的平台越多，条件越严格。脚本限制尝试次数，不会无限刷 IP，也不能保证指定国家或四个平台同时可用。

### 失败时怎么处理

- **“检测失败”**：没有取得有效结果，可能是连接或检测接口暂时异常，不等于已经确认被平台封锁。
- **“受限”**：检测到了平台的限制响应；换身份也不保证解除限制。
- **连接或 DNS 暂时失败**：脚本会尝试备用解析和当前连接的恢复。复核仍失败时会停止继续注册，保留原身份。
- **提示“注册状态不确定”“清理失败”或“恢复不完整”**：先保留提示路径中的恢复文件，按提示排查；不要靠删除文件反复尝试换身份。

## Cloudflare 优选：给 Argo 节点增加入口选择

进入 `sb → 11. Cloudflare优选`，选择运行 cfy。未安装时，sb 会先安装，再打开 cfy。

cfy 会基于现有 Argo 节点生成一组 Cloudflare 入口，保留原节点的连接信息。生成成功后，更新客户端订阅即可看到这些节点。**它调整的是客户端连接入口；WARP 调整的是访问网站时的出口，两者作用不同。**

- 只有 IPv4 的 VPS，云优选默认只获取 IPv4 候选。
- 生成失败时，保留最近一次成功结果，已有节点服务继续运行。
- 修改节点信息或 Argo 域名后，需要重新运行 cfy，再更新客户端订阅。

更多用法见 [Pre-cfy 使用说明](https://github.com/Pretic/Pre-cfy#readme)。

## Argo 与订阅

### 临时隧道和固定隧道怎么选

| 方式 | 需要准备什么 | 使用时注意 |
| --- | --- | --- |
| 临时隧道 | 不需要自己的域名 | 重启或重新获取后，域名可能变化，需要更新客户端订阅。 |
| 固定隧道 | 自己的 Cloudflare 域名和隧道凭据 | 域名可保持固定，在 `sb → 4 → 4. 添加Argo固定隧道` 中设置。 |

`sb → 4 → 3. 重启Argo服务` 会根据当前隧道类型处理：固定隧道重启后保留域名；临时隧道会同步新域名到节点和订阅。如果用过 cfy，域名变化后还需重新生成优选节点。

### 查看或配置订阅

进入 `sb → 7. 管理节点订阅 → 5. 查看订阅链接与详细状态` 查看当前地址。

默认提供 HTTP 订阅。有自己的 Cloudflare 域名并已配置固定隧道时，可选择同一菜单中的 `6. 配置 Cloudflare HTTPS 订阅`，跟随向导完成设置。配置成功并验证可访问后，脚本才会优先展示 HTTPS 地址；不需要为它额外映射公网端口。

- “关闭节点订阅”会同时停止 HTTP 和 HTTPS 订阅，已有节点仍可使用。
- “关闭 Cloudflare HTTPS 订阅”只关闭 HTTPS，保留 HTTP。
- “重新生成订阅密钥”会让旧订阅地址失效，需要在客户端换成新地址。

## 更新与卸载

### 更新 sb

已安装的 VPS 执行：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Pretic/Sing-box-Pre/main/sing-box.sh) --update
```

这只更新管理脚本，不重装 sing-box，也不修改已有节点、端口、订阅或隧道配置。完成后退出旧菜单，重新输入 `sb`。

cfy 单独更新，在 Cloudflare 优选菜单选择“更新 cfy”，或运行：

```bash
cfy --update
```

### 卸载

进入 `sb → 2. 卸载sing-box`，按提示操作。

注意命令含义：`--update` 是更新，**`-u` 是卸载**。

## 其他常见问题

| 问题 | 先检查什么 |
| --- | --- |
| Reality 连不上，但 Argo 能用 | Reality 的 TCP 端口是否已在服务商和防火墙放行，NAT 映射是否对应。 |
| Argo 重新获取域名后旧节点失效 | 更新客户端订阅；使用过 cfy 时先重新运行 cfy。 |
| 订阅能导入，部分节点不能连接 | 在实际客户端网络上逐个测试；优选结果不保证每个入口始终可用。 |
| 没看到 HY2/TUIC | 默认不输出 UDP 节点，这是预期行为。 |
| 更新后菜单还是旧样子 | 退出当前菜单，重新运行 `sb`。 |

<details>
<summary>可选设置：节点名、订阅地址和 UDP 节点</summary>

大多数用户无需设置这些变量。需要时，在安装命令前指定：

| 变量 | 用途 |
| --- | --- |
| `NODE_NAME` | 自定义完整节点名前缀，例如 `US-MyVPS`；默认根据国家和 VPS 主机名生成。 |
| `PROMPT_NODE_NAME=1` | 使用无交互安装命令时，仍提示输入 VPS 名称。 |
| `SUB_HOST` | 指定订阅使用的域名或 IP。 |
| `SUB_ADDR_FAMILY` | 订阅地址默认使用 `ipv4`；也可指定 `ipv6` 或 `auto`。 |
| `INCLUDE_UDP_LINKS` | 默认 `0`；显式设为 `1` 才把 HY2/TUIC 加入默认节点输出。使用前需确认 UDP 端口可达。 |

例如，自定义节点名前缀：

```bash
NODE_NAME=US-MyVPS bash <(curl -fsSL https://raw.githubusercontent.com/Pretic/Sing-box-Pre/main/sing-box.sh) -i
```

</details>
