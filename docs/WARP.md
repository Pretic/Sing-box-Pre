# WARP 使用说明

## 更换出口

主菜单 `8 → 6` 默认持续寻找不同的 IPv4。每个候选都与原出口比较，并在正式核心激活后再次核对；没有通过验证就不删除原身份。地址相同或暂时故障会退避重试，Ctrl-C 可取消。明确 API 拒绝、未知注册结果、清理失败或配置并发变化会停止。

只需要改用 IPv4 时，选 `8 → 8`。它验证当前身份的 IPv4 后修改托管域名分流，不申请新身份。`ipv4_only` 只控制域名解析，不能把显式 IPv6 地址转换成 IPv4；其他自定义分流保留。

`sb --warp-health` 检查正式核心的 WARP 出口。首次使用会准备本机健康入口并重启核心。平台检测仅反映本次网页/地区响应，不保证登录、对话或视频播放。

## 小内存主机

有效容量不超过 256 MiB 时采用串行方式：暂停原核心，检测一个候选，回收候选后恢复原服务。失败及取消也执行恢复；重试等待期间原服务运行。一次检测可持续数十秒，平台检测可能更久。

剩余内存门槛为注册阶段 24 MiB、串行候选阶段 48 MiB、并行候选阶段 64 MiB，包含可见 cgroup 限制。它们是保守启动条件，不是预留或硬上限。实际运行占用仍取决于核心与负载。

## 配套组件

安装、更新及首次需要注册时，会取得本仓库固定版本 Release 中的对应架构成品，校验压缩包、解压后的 SHA-256 和 ELF 架构，再原子替换。组件仅在本地密钥生成和注册/删除请求时运行，不新增常驻服务。

下载或校验失败时，保留原组件和身份；网络恢复后重试。已有自定义程序不会被覆盖。默认路径为 `/usr/local/lib/sing-box-pre/warp-registration-adapter`；自定义路径可用 `SB_WARP_ADAPTER` 指定，但须支持配套接口。组件需要系统可信 CA 证书。

## 可选参数

- `WARP_ROTATION_MAX_BATCHES`：限制重试批次，默认不限
- `WARP_ROTATION_MAX_SECONDS`：限制总时长，默认不限
- `SB_WARP_PROBE_MODE=serial`：强制串行
- `SB_WARP_PROBE_MODE=parallel`：保留原服务并运行候选，不适合小机

未测过的内核、受限容器和实际流量负载可能不适用。恢复失败时按终端提示保留备份，先处理服务问题，不要反复清除恢复材料或注册新身份。
